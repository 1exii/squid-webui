Root CA Certificate Downloads

To avoid SSL/TLS certificate warnings and HSTS blocking, download and install the internal Root CA certificate onto your client devices.

⬇️ Download CA Cert (.crt) for Windows / macOS / iOS ⬇️ Download CA Cert (.pem) for Linux

Windows 10 / 11 / Server Client Onboarding Manual

Target Platform: Windows 10/11

1. Architecture & HSTS Prevention

This environment uses Transparent Network Interception. Windows clients do NOT require manual proxy configurations in System Settings or Internet Options.

  • Router Redirection: The ASUS Router detects HTTP (80) & HTTPS (443) traffic from registered client IPs and redirects it to the Squid proxy.
  • SSL Bumping: Squid inspects TLS traffic and dynamically generates site-specific certificates signed by the internal Root CA (squid.local).
  • HSTS Prevention: Popular domains like Google, GitHub, and Twitter enforce HSTS. Installing the Root CA into the Local Machine Trusted Root Store ensures Edge, Chrome, and system services recognize squid.local as a valid Root Authority, eliminating HSTS errors.

2. Router Registration (Administrator Step)

Before a Windows client can be proxied, its IP must be registered in proxy-hosts.conf and deployed via router firewall script.

3. Install Root CA Certificate on Windows Client

To prevent NET::ERR_CERT_AUTHORITY_INVALID and HSTS hard-blocks, install the Root CA into the system-wide Local Machine store:

Method A: Automated PowerShell Installation (Recommended)

Open PowerShell as Administrator on the Windows machine and run:

Import-Certificate -FilePath "$HOME\Downloads\squid-ca.crt" -CertStoreLocation "Cert:\LocalMachine\Root"
Method B: Graphical Interface (GUI) Installation
  1. Press Win + R, type certlm.msc (Local Computer Certificate Manager), and press Enter.
  2. In the left pane, expand Trusted Root Certification Authorities → Certificates.
  3. Right-click Certificates → All Tasks → Import...
  4. Click Next, browse to squid-ca.crt, and select Place all certificates in the following store: Trusted Root Certification Authorities.
  5. Click Next → Finish and confirm the security prompt.

4. Browser-Specific Setup & HSTS Clearing

  • Microsoft Edge & Google Chrome: Automatically trust the certificate once imported into Cert:\LocalMachine\Root. If HSTS is cached, visit chrome://net-internals/#hsts, enter the domain under Delete domain security policies, and click Delete.
  • Mozilla Firefox: Type about:config in Firefox address bar, search for security.enterprise_roots.enabled, set it to true, and restart Firefox.

Ubuntu Linux Client Onboarding Manual

Target Platform: Ubuntu / Debian

1. Automated One-Liner Installation (Fastest)

Open a terminal on your Ubuntu machine and run the following command to download the CA certificate, update system trust stores, and set proxy environment profiles automatically:

curl -sSL http://192.168.1.91:3131/download/install-ubuntu.sh | sudo bash

2. Manual Installation Steps

Step 1: Download & Install System Root CA
sudo wget -O /usr/local/share/ca-certificates/squid-proxy-ca.crt http://192.168.1.91:3131/download/cert.pem
sudo update-ca-certificates
Step 2: Import into Chrome / NSS Certificate Database
sudo apt-get install -y libnss3-tools
certutil -d "sql:$HOME/.pki/nssdb" -A -t "C,," -n "squid.local" -i /usr/local/share/ca-certificates/squid-proxy-ca.crt
Step 3: System-Wide Environment Proxy Settings
cat << 'EOF' | sudo tee /etc/profile.d/squid-proxy.sh
export http_proxy="http://192.168.1.90:3128"
export https_proxy="http://192.168.1.90:3128"
export HTTP_PROXY="http://192.168.1.90:3128"
export HTTPS_PROXY="http://192.168.1.90:3128"
export no_proxy="localhost,127.0.0.1,192.168.0.0/16,local,.local"
export NO_PROXY="localhost,127.0.0.1,192.168.0.0/16,local,.local"
EOF
sudo chmod 755 /etc/profile.d/squid-proxy.sh

3. Verification & Testing

# Test HTTPS request through proxy profile
. /etc/profile.d/squid-proxy.sh
curl -v https://google.com
