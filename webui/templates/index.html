Root CA Certificate Downloads

To avoid SSL/TLS certificate warnings and HSTS blocking, download and install the internal Root CA certificate onto your client devices.

⬇️ Download CA Cert (.crt) for Windows / macOS / iOS ⬇️ Download CA Cert (.pem) for Linux ⬇️ Download Proxy Auto-Config (.pac)

Windows 10 / 11 / Server Client Onboarding Manual

Target Platform: Windows 10/11

1. Reliable HTTPS Proxying

Use the WebUI-hosted Proxy Auto-Config (PAC) file for browsers. Transparent HTTPS interception remains available, but CDN hostnames with rapidly rotating DNS addresses can be rejected by Squid's mandatory destination verification.

  • PAC URL: http://192.168.1.91:3131/proxy.pac sends Internet traffic through 192.168.1.90:3128 while keeping LAN destinations direct.
  • Router Safety Net: The ASUS Router continues redirecting direct HTTP, HTTPS, and Spotify AP traffic from registered client IPs.
  • SSL Bumping: Squid inspects TLS traffic and dynamically generates site-specific certificates signed by the internal Root CA (squid.local).
  • HSTS Prevention: Installing the Root CA into the Local Machine Trusted Root Store ensures Edge, Chrome, and system services recognize squid.local.

2. Automated Windows Installation (Recommended)

Open PowerShell as Administrator, download the installer, and run it in the target user's session. It installs the CA and configures the Windows system PAC setting used by Chrome and Edge.

⬇️ Download Windows Installer (.ps1) 
Set-ExecutionPolicy -Scope Process Bypass
& "$HOME\Downloads\install-windows.ps1"

3. Manual Windows Setup

Install the Root CA
Import-Certificate -FilePath "$HOME\Downloads\squid-ca.crt" -CertStoreLocation "Cert:\LocalMachine\Root"
Configure the PAC URL
  1. Open Settings → Network & Internet → Proxy.
  2. Under Use setup script, select Set up.
  3. Enable it and enter http://192.168.1.91:3131/proxy.pac.
  4. Save, then restart Chrome or Edge.

4. Browser-Specific Setup & HSTS Clearing

  • Edge & Chrome: If HSTS is cached, visit chrome://net-internals/#hsts and delete domain security policy.
  • Firefox: In about:config, set security.enterprise_roots.enabled to true.

Ubuntu Linux Client Onboarding Manual

Target Platform: Ubuntu / Debian

1. Automated CA + PAC Installation (Recommended)

curl -sSL http://192.168.1.91:3131/download/install-ubuntu.sh | sudo bash

The installer trusts the Squid CA, installs a managed Chrome/Chromium PAC policy, and configures the active GNOME session when available.

2. Manual Installation Steps

Step 1: Download & Install System Root CA
sudo wget -O /usr/local/share/ca-certificates/squid-proxy-ca.crt http://192.168.1.91:3131/download/cert.pem
sudo update-ca-certificates
Step 2: Import into Chrome / NSS Certificate Database
sudo apt-get install -y libnss3-tools
certutil -d "sql:$HOME/.pki/nssdb" -A -t "C,," -n "squid.local" -i /usr/local/share/ca-certificates/squid-proxy-ca.crt
Step 3: Configure GNOME Proxy Auto-Config
gsettings set org.gnome.system.proxy autoconfig-url 'http://192.168.1.91:3131/proxy.pac'
gsettings set org.gnome.system.proxy mode 'auto'

Chrome uses the explicit proxy selected by the PAC file; LAN addresses remain direct. The router redirect remains a safety net for applications that ignore desktop proxy settings.

3. Verification & Testing

curl -v https://google.com
